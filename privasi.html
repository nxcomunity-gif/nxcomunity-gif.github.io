Privasi & Ketentuan

Berlaku untuk tools di nxcomunity-gif.github.io, termasuk fitur "Login pakai Roblox".

Data yang kami pakai

  • Saat login pakai Roblox, kami menerima ID, username, dan foto profil akun Roblox kamu, plus izin untuk meng-upload aset ke akun kamu.
  • Password Roblox kamu tidak pernah melewati web ini. Login dilakukan langsung di halaman resmi Roblox.
  • Token akses Roblox disimpan di server NX supaya upload bisa jalan, dan tidak pernah dikirim ke browser atau pihak lain.
  • Gambar skybox yang kamu upload hanya dikirim ke Roblox atas nama akun kamu dan tidak disimpan di server NX.

Untuk apa

Hanya untuk meng-upload gambar skybox yang kamu pilih ke akun Roblox kamu dan membuat file Sky (.rbxmx). Data tidak dijual atau dibagikan.

Mencabut akses

Klik Keluar di tool untuk menghapus sesi dan mencabut token. Kamu juga bisa mencabut izin kapan saja di Roblox: Settings → Security → Third-party app authorizations (Aplikasi pihak ketiga).

Ketentuan

  • Tools disediakan gratis apa adanya.
  • Kamu bertanggung jawab atas gambar yang kamu upload dan wajib mematuhi aturan komunitas Roblox. Gambar tetap melalui moderasi Roblox.
  • Pertanyaan: hubungi admin di Discord NX COMMUNITY.
