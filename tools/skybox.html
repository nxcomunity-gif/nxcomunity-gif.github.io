Skybox Converter

Upload gambar panorama 360° (rasio 2:1, equirectangular), terus jadi 6 sisi skybox: Bk, Dn, Ft, Lf, Rt, Up. Semua diproses di HP/PC kamu, nggak di-upload ke mana-mana.

Panorama 360°: gambar dipakai penuh mengelilingi langit (cocok buat gambar 2:1 / prompt AI "equirectangular"). Gambar biasa: gambar dicerminkan biar ujung kiri-kanan nyambung, tepi atas & bawah ditarik sampai nutup langit. Cermin langit: bagian bawah diisi pantulan langit, jadi map kelihatan melayang di atas awan. Rotasi Up/Dn cuma buat penyesuaian kalau masih ada yang kurang pas.

Langkah 2 • Cara cepat

Upload otomatis ke Roblox → langsung jadi 1 file Sky

Klik tombol di bawah: 6 gambar di-upload ke Roblox lewat server NX, terus file Sky .rbxmx langsung ke-download dengan ID yang udah keisi. Nggak perlu login.

Belum login

⚠️ Gambar kena moderasi Roblox dulu (biasanya beberapa menit) sebelum langitnya kelihatan. Jangan upload gambar yang melanggar aturan Roblox.

Langkah 2 • Cara manual

Jadiin file Sky Roblox (.rbxmx)

File Roblox nggak bisa nyimpen gambar, cuma ID-nya. Jadi: upload 6 gambar tadi di Roblox Studio (View → Asset Manager → Bulk Import), klik kanan tiap gambar → Copy Asset ID, tempel di bawah. Boleh angka doang, rbxassetid://…, atau link Creator Store.

Cara pakai: drag file .rbxmx ke jendela Roblox Studio (atau klik kanan Lighting → Insert from File), terus pindahin Sky-nya ke dalam Lighting. Kalau di Lighting udah ada Sky lain, hapus yang lama.
